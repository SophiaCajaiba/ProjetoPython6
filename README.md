AULA DE AOC
Autora: Sofia Sousa Cajaiba

Exercício 1: Criação de 5 Threads com identificação por ID e pausa de 0,5 segundos antes da impressão.

Exercício 2: Criação de 3 Threads para calcular a soma de 5 valores aleatórios, com pausa de 0,2 segundos a cada iteração.

Exercício 3: Simulação de uma corrida de sapos utilizando 5 Threads, com saltos aleatórios de 1 a 5 cm até atingir a distância máxima.
